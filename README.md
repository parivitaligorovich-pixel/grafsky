# ЖК «Графський» — концепт першого екрана

Концепт редизайну сайту [grafsky.com.ua](https://grafsky.com.ua/): перший екран і блок переваг.

- Перший екран: композиція з двох фото, інтро-анімація, розгортання фото на весь екран при скролі.
- Блок переваг: 4 кроки скролу, 3D-сітка, що реагує на курсор, як вода.
- Сітка 4/8 px, мінімальний шрифт 12 px, адаптив до 375 px.

Запуск: відкрити `index.html` через будь-який локальний сервер, напр. `python3 -m http.server`.

Фото й тексти взято з grafsky.com.ua.
